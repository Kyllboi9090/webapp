It's a light weight social media Web app and can be improved for better results or production.
Use the python3 app2.py to start it.
Use sqllite3 social.db to view database.

The verification code will be sent on server side if smtp server not set up

For real email:Set up environment variables 
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=you@gmail.com
SMTP_pass=<app password>
